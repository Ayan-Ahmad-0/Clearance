Methodology & limitations

  • Access rules and ACLs are synthetic; the NIST text is real and public.
  • Example answers are precomputed; questions you type run live (rate-limited).
  • Index benchmarks ran on 60,000 and 400,000 chunks (synthetic vectors).
  • Zero leaks is a measured result for these runs, not a proof of security.
